# zone2.day

Личное приложение для тренировок на выносливость (бег → триатлон), где тренер — AI.

- **AI-тренер** (claude.ai) управляет планом и видит тренировки через MCP: `https://api.zone2.day/mcp`.
- **Бэкенд**: Deno + Hono + Postgres (Supabase Free) за Cloudflare-прокси.
- **iOS**: офлайн-first SwiftUI-приложение — план сам появляется на телефоне и на часах.
- **Apple Watch Ultra 2**: исполнение через WorkoutKit; позже свой раннер с постоянным сторожем пульса.
- **Данные**: Apple Health → сервер (полный дамп + FIT); MyWhoosh → intervals.icu → сервер.
