# 07. iOS-приложение: UX и UI

Единственный фронтенд. Требования: **офлайн, чётко, приятно, без ручных обновлений**. Референс blocks.zone посмотрели, но не копируем.

## 1. Принципы

1. **Сначала главное.** Главный экран — «что делать сегодня и зачем», а не календарь.
2. **Доверие к доставке.** Всегда видно: когда обновлялось и есть ли тренировка на часах.
3. **Структура читается за секунду.** Повторы свёрнуты (`6 × [12 s sprint / 1:45 walk]`), главный таргет крупно (то, что будет на часах), второстепенные — мельче.
4. **План и факт — один объект.** После выполнения карточка тренировки становится карточкой «план vs факт», а не второй карточкой рядом.
5. **Нативность.** SF Pro для текста, моноширинные цифры (`.monospacedDigit()`) только в числах, Dynamic Type, тёмная тема, haptics, системные жесты. Никакого «моноширинного всего».
6. **Читаемость на улице.** Высокий контраст, крупные таргеты, тёмная тема по умолчанию следует системе.
7. **Ввод — только в зале.** Остальное — просмотр. Обратная связь — через чат.

## 2. Навигация

TabView: **Today · Calendar · Activities · Profile**. Debug — скрытый экран (долгое нажатие на версию в Profile; в debug-сборке — отдельная вкладка).

## 3. Экраны

### 3.1 Today
- Строка состояния: `Updated 18:02 · On watch ✓` (или предупреждение с причиной).
- **Карточки сегодняшних тренировок** — две в день норма (утро/вечер, бег + зал): упорядочены по времени, ближайшая невыполненная — раскрыта, остальные компактны. Карточка: вид спорта, название, время (если задано), **goal** (зачем), профиль структуры (полоски шагов: ширина — длительность, высота — интенсивность, цвет — зона), ключевые цифры (время, дистанция, нагрузка), режим исполнения (`On watch · Workout app` / `Zone2 Watch` / `MyWhoosh → Share .zwo` / `Gym`).
- Если тренировка выполнена — компактный итог «план vs факт» и заметки тренера (AI).
- Ниже: завтра и следующие 2–3 дня (компактно), ближайший принятый старт (обратный отсчёт — если дата точная; идеи стартов здесь не показываются).
- Восстановление одной строкой: HRV, пульс покоя, сон относительно базлайна (без вердикта — вердикт в чате).

### 3.2 Calendar
- Вертикальный список недель (бесконечный скролл в обе стороны), неделя = заголовок с объёмом план/факт по видам спорта + дни.
- День: тренировки (план, факт, статус: done / partial / missed), старты, отметки.
- Переключатель на месячную сетку (точки по видам спорта).

### 3.3 Planned workout
- Заголовок: спорт, название, дата, ключевая; **goal**; notes.
- **График структуры** (Swift Charts): шаги по времени или дистанции, высота — интенсивность в абсолютных таргетах. Переключение Pace / HR / Power / RPE — только если таргеты заданы по нескольким метрикам.
- **Шаги:** дерево с свёрнутыми повторами, у шага — главный таргет крупно, второстепенные мелко, длительность, заметка.
- Оценки: время, дистанция, нагрузка, время в зонах (план).
- Доставка: «On watch since 18:04 (v7)» / причина, если нет.
- Действия: `Share .zwo` (для станка), `Open in Workout app` (превью WorkoutKit), `Start on Zone2 Watch` (ф.2).

### 3.4 Completed (план vs факт) / Activity
- Сводка: время, дистанция, средние, нагрузка, оценка (grade) и **coach notes** (markdown от AI).
- **Главный график:** блоки плана полупрозрачным фоном, поверх — фактическая линия пульса, темпа или мощности; для каждого шага метка попадания (✓ / ↑ / ↓).
- Таблица интервалов: таргет → факт → % времени в таргете.
- Карта трека (MapKit), сплиты по км, зоны, дрейф пульса, механика бега, бассейн (отрезки, SWOLF).
- Источник и файлы (Health, intervals.icu / MyWhoosh, merged).

### 3.5 Gym mode (силовая)
- Открывается из Today или из тренировки; экран не гаснет (`isIdleTimerDisabled`).
- Список упражнений; текущее раскрыто: подходы строками `55 kg × 8 · RPE 6` (префилл из плана).
- **Тап по подходу = выполнено как в плане.** Долгое нажатие или свайп → правка веса и повторов (степперы ±2.5 кг / ±1, плюс цифровая клавиатура).
- Таймеров отдыха и учёта времени нет — только что сделано: вес и повторы (для статики — секунды удержания).
- Заметка к упражнению (одна строка, свободный текст, разберёт AI).
- Всё пишется в GRDB мгновенно, отправляется через outbox. Офлайн — норма.
- «Finish» → сессия закрыта; при наличии — привязка к `HKWorkout` силовой с часов.

### 3.6 Profile
- Пороги и зоны (только чтение, источник — AI), оборудование, сторож пульса (ф.2).
- Подключения: Apple Health (разрешения, последняя выгрузка), intervals.icu (ввод API-ключа — единственное поле ввода вне зала), сервер (аккаунт, выход).
- Язык данных AI и часовой пояс — только чтение.

### 3.7 Debug
Курсор синка, последние синки (триггер, длительность, результат), outbox (с кнопкой «retry»), карта «запланировано на часах», разрешения HealthKit, последние фоновые пробуждения, логи (поделиться), переключатель сервера (только debug-сборка), «Full resync».

## 4. Дизайн-система (пакет Zone2UI)

- **Цвета зон** — единая шкала Z1–Z5 (плюс спринт/анаэробная), согласованная для графиков, полосок и чипов; проверка контраста в светлой и тёмной теме.
- **Цвета видов спорта** — бег, вело, плавание, силовая, другое.
- Компоненты: `WorkoutProfileBar`, `StepRow`, `RepeatGroup`, `TargetChip`, `PlanVsActualChart`, `IntervalTable`, `DeliveryStatus`, `MetricTile`, `SetRow`.
- Каждый компонент и экран — с превью и snapshot-тестами (light/dark, Dynamic Type L/XXXL, en/ru).
- Перед вёрсткой — **макеты ключевых экранов** (Today, Planned workout, Completed, Gym), согласование с атлетом.

## 5. Локализация
- String Catalog (`Localizable.xcstrings`), en — базовый, ru — второй; плюрализация.
- Числа и единицы — `Measurement` + `FormatStyle` (темп — собственный форматтер `m:ss /km`).
- Тексты от AI (title, goal, notes, coach notes) показываются как есть.
- Push-тексты (ф.3) — `loc-key`, локализуются на устройстве.

## 6. Виджеты и мелочи (ф.2)
Виджет на экран блокировки и домой: «Сегодня: тренировка(и) · главный таргет». Усложнение на циферблате часов (с приложением для часов).
