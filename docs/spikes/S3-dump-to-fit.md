# Спайк S3 — дамп HealthKit → FIT

Дата: 2026-11-20. Код: `backend/src/domain/fit_encode.ts` (`dumpToFit`), прогон: `backend/scripts/s3_fit_roundtrip.ts <dump.json.gz>… [--out dir]`, тест: `backend/tests/fit_encode_test.ts`.

## Вопрос
Можно ли из дампа HealthKit собрать валидный FIT активности (для Strava, intervals.icu, `get_activity_file kind=fit`), в котором ряды и круги совпадают с исходником?

## Как проверяли
Взяли 7 реальных дампов из prod (бег с GPS ×2, вело на улице, бассейн 50 м, поход 4,3 ч с паузой 32 мин, беговые лыжи, зал). Прогнали по кругу: дамп → `dumpToFit` (`@garmin/fitsdk` Encoder) → проверка целостности и декодирование Garmin SDK → наш `fitToDump` → `summarize`/`lapsOf`. Сравнивали с тем же кодом, запущенным на исходном дампе.

## Что в файле
- `file_id` (`manufacturer: development`, `product_name: zone2.day`) и `device_info` creator с именем устройства из Health.
- `record` раз в секунду по настенному времени: дистанция (накопленная из интервальных сэмплов), координаты и высота (вне помещения), пульс (линейная интерполяция при разрыве ≤30 с), мощность, скорость (беговая скорость часов → GPS → дистанция за 10 с), каденс (бег: шаги за 10 с → strides/min + `fractional_cadence`; вело: rpm), беговая динамика (`vertical_oscillation`, `stance_time`, `step_length`).
- Паузы HK (`pause`/`resume`) → `event timer stop/start`.
- Один набор кругов: ручные интервалы (маркеры), а если их нет, то первая автоматическая цепочка (сегменты или км-сплиты). Без кругов — один круг на всю тренировку. Бассейн: сеты как `lap` и каждая длина как `length` (гребки, стиль).
- `session` и `activity` с итогами из `summarize`; `local_timestamp` по поясу тренировки.

## Найдено по ходу
- **`durationSec` в HealthKit не включает паузы**, а FIT различает `total_elapsed_time` (настенное время) и `total_timer_time`. Первая версия строила сетку по `durationSec` и обрезала хвост похода на 32 минуты (−13 % трека, неверное время в движении). Теперь кодировщик пишет elapsed = end − start и timer = `durationSec`. Декодер `fitToDump` исправлен так же: `durationSec` = timer, `end` = start + elapsed. Для MyWhoosh ничего не меняется, у них timer = elapsed.
- **В FIT помещается только один набор кругов.** У Apple бывают параллельные цепочки: км и мили, или, как у лыж, две цепочки сегментов. В FIT идёт одна (ручные → км → первая), остальные остаются только в дампе.
- **Пульс внутри короткой длины** в бассейне может отличаться на несколько ударов: в FIT он раз в секунду с интерполяцией, а `lapsOf` на дампе усредняет редкие исходные сэмплы. Итоги тренировки совпадают.

## Вывод
✅ Риск снят: собственный энкодер не нужен, хватает `@garmin/fitsdk` Encoder. FIT — производная от дампа с потерями (1 Гц, один набор кругов). Источником истины остаётся дамп (D9, D47).

⏳ Внешняя проверка 👤: загрузить `~/Downloads/zone2-S3/{run,swim,hike}.fit` в intervals.icu (или Strava) и сверить трек, круги и длины. После загрузки удалить, чтобы не было дублей.
