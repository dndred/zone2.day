# Спайк S8 — станок ThinkRider X2Max по Bluetooth (FTMS)

Дата: 2026-11-20. Код: `tools/ble-scout/` (`just ble-scout [сек]`). Контекст: [11-trainer](../11-trainer.md).

## Вопрос
Можно ли подключиться к станку напрямую, без MyWhoosh: читать мощность, каденс и скорость, а позже управлять нагрузкой (ERG)? Протокол стандартный (FTMS) или закрытый?

## Как проверяли
Сканер на Mac (CoreBluetooth) слушает эфир, подключается к устройствам с сервисами FTMS `0x1826`, Cycling Power `0x1818`, CSC `0x1816`, HR `0x180D`, читает все характеристики и подписывается на уведомления.

Особенность macOS: CLI-процесс, запущенный из Claude или терминала, падает (SIGABRT, TCC), если у «ответственного» приложения нет `NSBluetoothAlwaysUsageDescription`. Решение: собрать сканер как `.app`-бандл с Info.plist и запускать через `open -W --stdout`. Тогда macOS спрашивает доступ у самого сканера.

## Результат: станок — стандартный FTMS

| | |
|---|---|
| Имя в эфире | `Think X222- 0105989` |
| Производитель / модель | ThinkRider / `20251201`, железо V1.1.0, прошивка V3.3.1 |
| Реклама | сервисы `1826` (FTMS) и `1818` (Cycling Power) |
| Сервисы | `1818` Cycling Power · `1826` Fitness Machine · `FD00` (свой) · `6E40FEC1-…` Nordic UART (родное приложение ThinkRider) · `180A` Device Information |
| Видимость | в эфире первые 1–2 мин после включения (по словам атлета; так же видит MyWhoosh) |

**FTMS `0x1826`:**

| Характеристика | Что | Значение |
|---|---|---|
| `2ACC` Fitness Machine Feature | machine `0x4003`: средняя скорость, каденс, мощность; target `0xA00C`: **целевое сопротивление, целевая мощность (ERG)**, симуляция уклона (indoor bike simulation), spin-down | ERG и SIM поддерживаются |
| `2AD2` Indoor Bike Data (notify) | флаги `0x0044`: мгновенная скорость (0,01 км/ч), каденс (0,5 об/мин), мощность (Вт) | ~4 уведомления/с |
| `2AD8` Supported Power Range | 0…2000 Вт, шаг 1 | |
| `2AD6` Supported Resistance Range | 0…200, шаг 1 | |
| `2AD9` Control Point (write + indicate) | управление: request control, set target power, simulation | для этапа ERG |
| `2ADA` Machine Status (notify) | | |

**Cycling Power `0x1818`:** `2A63` Measurement (notify, флаги `0x30` — есть накопленные обороты колеса и шатуна), `2A65` Feature `0x0000000E`, `2A5D` Sensor Location `0x0C` (rear wheel), `2A66` Control Point.

## Вывод
✅ Риск снят: закрытый протокол не нужен. Мощность, каденс и скорость читаются из стандартного FTMS Indoor Bike Data. Управление нагрузкой (ERG, симуляция) доступно через стандартный Control Point. Nordic UART и `FD00` не используем.

⏳ Осталось 👤: снять данные при вращении педалей (в замере велосипед не стоял на станке, всё было по нулям). Проверить, что мощность и каденс правдоподобны и частота уведомлений держится при нагрузке, и сравнить с FIT MyWhoosh на том же заезде.

## Пульс от HeartCast (2026-11-20)
HeartCast вещает пульс часов **с iPhone** («Andrei's iPhone»): сервис `180D`, `2A37` notify, формат uint8 (`06 3d` = 61). Примерно одно значение в 3–5 с; `06 00` (0) — нет данных. Mac подключается к iPhone параллельно с работой HeartCast. В рекламе iPhone UUID сервиса не виден (overflow area), но сканирование с фильтром `180D` его находит.
