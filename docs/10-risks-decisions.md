## 2. Риски

| # | Риск | Вероятность / влияние | Митигирующие меры |
|---|---|---|---|
| R1 | HealthKit или WorkoutKit недоступны на Personal Team | средняя / **критичное** | Спайк S1 первым; план Б — команда друга |
| R2 | Без push план не успевает доехать до выхода из дома | средняя / низкое (принято атлетом для ф.1) | Много фоновых триггеров + pull-to-refresh; спайк S4; push в ф.3 |
| R3 | Подпись истекла (7 дней) — приложение не запускается | высокая / среднее | `just resign` по launchd; тренировки на часах остаются; предупреждение в приложении за 2 дня |
| R4 | claude.ai не находит OAuth-метаданные или не проходит DCR | низкая (с прокси) / высокое | Спайк S2; тест на web и mobile |
| R5 | Лимиты Edge Functions (CPU, память, тело запроса) на ingest | средняя / среднее | Спайк S7; загрузка напрямую в Storage; ingest по частям |
| R6 | Free-проект Supabase засыпает или упирается в лимиты | низкая / среднее | Ежедневные синки держат проект активным; мониторинг объёма; план переезда (D3, D4) |
| R7 | WorkoutKit не поддерживает нужные конструкции (бассейн, вложенные повторы, Lap) | средняя / среднее | Спайк S1; деградация с предупреждением в `delivery_ack`; ф.2 — свой раннер |
| R8 | intervals.icu API: изменения или ограничения | низкая / среднее | Изолированный адаптер; fallback — Strava-стримы |
| R9 | Свой раннер уступает штатному в качестве записи | средняя / среднее | Критерии паритета (06-watch §3.4); штатный режим остаётся |
| R10 | Утечка медданных | низкая / высокое | Изоляция по `user_id` + тесты, токены хэшами, подписанные ссылки с TTL, шифрование ключей интеграций, debug-scope не выдаётся claude.ai |
| R11 | Разрастание MCP (слишком много инструментов, плохие descriptions) | средняя / среднее | Снапшот-контракт, ревью descriptions в живом чате, ~40 инструментов |
| R12 | У Supabase Free нет бэкапов | высокая / высокое | Еженедельный `pg_dump` в Storage + копия на Mac (`just backup`) |
